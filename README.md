# PGM611 - Scripting - Condoreno Eduardo

Proyecto de Unity de la materia **PGM611 - Scripting** (Unifranz).

## Datos del proyecto

- **Nombre:** Cualquier Juego
- **Unity:** 6000.3.16f1
- **Render Pipeline:** Universal Render Pipeline (2D / Renderer2D)
- **Input:** Input System (`Assets/InputSystem_Actions.inputactions`)

## Estructura

```
Assets/
  Scenes/                            escena principal (SampleScene)
  Settings/                          configuracion de URP y plantillas de escena
  Legacy-Fantasy - High Forest 2.3/  sprites, tilesets y animaciones
Packages/                            dependencias del proyecto
ProjectSettings/                     configuracion de Unity
```

## Como abrirlo

1. Clonar el repositorio.
2. Abrir Unity Hub, **Add > Add project from disk** y seleccionar la carpeta clonada.
3. Abrir con la version **6000.3.16f1** de Unity.

La carpeta `Library/` no esta versionada: Unity la regenera sola la primera vez que se abre el proyecto.
